GPT-2 from scratch, with my own KV cache and LoRA

Every layer hand-written: attention, RoPE, training loop, sampling. No Hugging Face.

How it was measured

124M parameters (12 layers, 12 heads, d768), trained on TinyStories for 10k steps (~61M tokens, ~5 h on a T4) to validation loss 1.5647. KV cache: 1.64× on a T4, 5.7× on Apple MPS. LoRA (rank 8) cut Shakespeare perplexity 4.31× in 20 minutes on a MacBook Air.

Agents · Evaluation

glassbox-agent: an agent graded on how it fails

A tool-using agent loop from scratch, plus an eval harness where 3 of 10 tasks are designed to fail.

  • 10/10harness agreement
  • 0frameworks

Repository ↗Agent loop ↗Eval harness ↗
What the failures test

A step cap that must stop the loop, a missing tool that must produce a refusal, and an unverifiable fact that must not be guessed. Run 1 exposed a scorer bug (printed 8/10, truly 7/10); after the fix, Run 2 scored 10/10 with no hidden crashes.

Research

Neural architecture search

Preprint · arXiv Nov 2026 → ICML 2027

Do LLMs actually search?

LLM-guided architecture search papers never compare against random search. I ran that comparison on NAS-Bench-201.

  • 0 / 4audited papers had the baseline
  • 0.60pts: random vs global best
  • 39 / 45LLM calls were repeats
Code and logs ↗Ablation result ↗
Builds on my M.Tech thesis

The thesis (IIT Kharagpur, 2025) used information-geometric search (MIGO) to find architectures for morph-attack detection across 6 datasets and 132 GPU-hours, reaching 81.67% cross-dataset accuracy. The paper asks the next question: is an LLM a good way to search at all?
